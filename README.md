# 창업 세무회계 노트

법인을 세우고 운영하는 대표가 알아야 할 세무, 회계 내용을 23개 장으로 정리한 학습 사이트.

## 구성

- 설립 전, 회계 기초, 세금, 운영, 투자와 상장, 확장과 정리 6개 묶음
- 장마다 확인 문제와 공식 확인처 링크
- 세무 일정: 12월 결산 법인 기준, 주말과 공휴일이면 다음 영업일로 표시
- 계산기: 4대보험료, 법인세 산출세액, 부가세, 투자 후 지분율
- 용어 96개, 설립 체크리스트
- 학습 기록은 브라우저 localStorage에 저장

## 실행

빌드 과정 없음. `index.html`을 브라우저로 열면 됨.

## 파일

| 파일 | 내용 |
|---|---|
| `js/content.js` | 1 ~ 13장 기본 챕터, 세무 일정, 공휴일, 체크리스트 |
| `js/content-tax.js` | 세금 한눈에 보기, 청년 창업자 세법, 절세 방법 |
| `js/content-invest.js` | 투자 유치, 계약 조항, 지분 희석, 투자 후 회계, 상장, 엑싯 |
| `js/content-more.js` | 해외 진출, 지분 증여와 승계, 폐업과 청산 |
| `js/glossary.js` | 기본 용어 |
| `js/app.js` | 화면 전환, 퀴즈, 일정 계산, 계산기 |
| `css/style.css` | 스타일. 375px 폭까지 대응 |

## 내용 수정

- 세율, 요율, 한도는 기준 연도를 함께 적어 둠. 개정되면 해당 챕터 파일 수정
- 계산기 요율은 `js/app.js`의 `RATES_2026`, `CIT`에 따로 있음
- 해가 바뀌면 `js/content.js`의 `HOLIDAYS`에 그해 공휴일 추가

## 주의

일반적인 학습용 정리이며 기준일은 2026년 11월. 실제 신고 전에는 국세청 홈택스, 국가법령정보센터, 담당 세무사를 통해 확인.
